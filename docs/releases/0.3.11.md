## 新功能

- 新增内置终端配色方案 Snazzy，深色和浅色外观各自记住所选方案。
- 连接设置页新增主机标签管理器：每个标签显示主机数，支持重命名（自动合并到同名标签）和删除，删除需要两次确认。
- SFTP 支持多选后一次移动到所选文件夹，逐项保留文件名，部分失败时逐条提示。

## 改进

- 笔记窗口按上次使用的模式打开，不再总是回到预览；模式跨保存和恢复保留。
- 删除代码片段需要两次按压确认，页面和右键菜单里的删除按钮一致。

## 修复

- 标签重命名对话框未注册到模态绘制分发，导致打开后无法交互。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
