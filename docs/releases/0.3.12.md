## 新功能

- 双击标签页名称即可原地重命名（分栏窗格栏此前已支持）。
- 应用内一键自更新闭环：更新检查直接读取本仓库 release 的校验和与签名，安装器安装和便携版都能在应用内完成更新，不再需要去发布页手动下载。

## 改进

- 主机列表的滚动条在指针移入时出现，并且可以拖动。
- 快捷命令页的表格可以滚动，条目再多也能看全。
- 主机和分组按当前界面语言排序：中文界面按读音排列，不再按编码顺序。
- 同步失败的提示显示完整原因，不再截断。
- 传输中心的滚动条预留了自己的条带，不再压在卡片上造成裁切。

## 修复

- 终端输出到达时不再丢失选区。
- 行被重写后行首时间随之刷新。
- 可以连接链路本地 IPv6 地址：Windows 网卡名带方括号时握手不再中断。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
